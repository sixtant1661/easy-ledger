## 2. 可靠使用与批量补录

优先完成用户可用的手动备份恢复、误删撤销/恢复策略、迁移验证，再扩展批量录入。备份使用系统文件选择器，恢复前校验和保护当前数据，测试损坏文件、版本不兼容、磁盘空间不足及中断回退。

批量补录复用单条领域规则与表结构，支持日期范围、连续日期、休息日跳过、上一天复制和遗漏补记。批量保存事务边界需明确：推荐先逐日校验，有限规模一次原子提交；大范围需定义批次和失败续录语义。避免两种录入形成不同金额结果。

验收：同样输入经两种方式产生一致数据；休息日和跨日区间正确；失败不造成无提示的部分记录；备份后恢复与原数据一致。

## 3. 统一结算与 Excel

收集原始 Excel 样式，使用匿名或合成样例；确认字段映射、签字区、纸张、分页和小数格式。建立 SettlementDocument、范围选择、APP 表格预览和不可变历史快照。选定兼容 Android 的 .xlsx 库，生成专业换行与打印布局。

验收：多时间段每段一行；Excel 行高、列宽、边框、换行、合计及签字区正确；使用目标手机办公软件和桌面软件打开检查；修改源记录不改变已保存快照。模板未提供时，不将“完全复刻”列为已完成。

## 4. PDF、PNG 和系统分享

基于同一结算文档增加 PDF、PNG 渲染及系统分享。验证长单分页、大图片内存与分享权限生命周期；微信测试依赖实际设备、安装状态和接收应用。

验收：不同格式的记录内容、排序、数量、金额、列名及合计一致，文件可读；没有截断、空页或内存崩溃；不扩大存储权限。

## 5. 发布质量

覆盖数据库历史版本迁移、备份恢复、极端输入、大量记录、离线运行、生命周期和无障碍。确定最低系统及设备矩阵，采用内部测试后再发布。正式签名与密钥由安全环境管理，Debug APK 不等于可公开发布版本。

## 0.2 本地工作记账里程碑

目标设备已确认 Galaxy S21 FE / Android 16 / One UI 8.0，基础版已有用户实机验收。本轮保留原风格和导航，增加 Room 本地项目/记录、手动数量计费、日历和快捷日期、历史详情、关键词搜索与首次三步引导。工时段输入、批量补录、导出及备份恢复未实现。

用户已确认数量大于 0、单价允许 0、拒绝负数冲销、小时数量最多两位小数；按天手填。金额继续精确十进制 HALF_UP 两位并合计舍入后各行金额。记录单价独立快照，不受项目默认单价修改影响。

实际 Room v2 模型见 data/local：Project、WorkRecord、WorkSegment（未来扩展）、Preference。项目备注用于搜索，v1→v2 显式迁移增加备注列；v1 为测试基线，未向用户发布。项目/记录软删除，项目删除保留记录；数量改变不删除原时间段。项目列名和结算快照目前仍是后续设计，未声明实现。

首次引导完成/跳过持久化于 Room，设置入口可重看。搜索使用本地 SQL 字符串包含查询，百分号/下划线按字面关键词处理，不作为通配符。金额不使用 SQLite REAL 或 SUM(text)。多表写入事务化，不启用破坏性迁移。

验收必须包含新增/编辑/删除、价格快照、金额/舍入、搜索、事务回滚、数据库文件重开、v1→v2 迁移、引导和 UI、同签名覆盖安装的数据保留。测试结果按实际执行记录至 BUILD_STATUS。API 36（Android 16）模拟器不能代替三星 Android 16 真机验收。

下一优先项是可导出、校验、可回退的本地备份恢复，使用 SAF，不访问服务器。不将手机数据库、签名私钥或真实记录提交 Git。签名缓存失效拒绝更新包，固定发布密钥必须另行安全配置；卸载/清除数据会丢失记录。

本轮已有成功 Actions：38502595051，5 个 JVM + 11 个 Android 16 测试，以及实际同签名覆盖安装 seed/verify 检查均通过。新增/编辑/删除、搜索和引导已实现。下一任务优先本地导出备份恢复和固定安全签名，之后再继续工时段与专业结算导出；不合并 PR #1，不发布正式版本。
